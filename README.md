# Elohîm m'aime ! Le jeu

Jeu d'éveil chrétien pour les enfants de 3 à 6 ans, tiré du livre « Elohîm m'aime ! Mon livre d'éveil chrétien ».

Toutes les consignes sont lues à voix haute, pour les enfants qui ne savent pas encore lire.

## Contenu

10 aventures de 3 jeux chacune (30 étoiles à gagner) :

| Aventure | Jeux |
|---|---|
| 🌍 Les 7 jours | Ranger les jours · Quel jour ? · Paires de la création |
| 🚢 L'arche de Noé | Deux par deux · Paires d'animaux · L'histoire de Noé |
| 🌈 L'arc-en-ciel | Colorier l'arc-en-ciel · Rouge comme la pomme · Chasse aux couleurs |
| 🔢 Je compte | Compter les animaux · De 1 à 10 · Où y en a-t-il le plus ? |
| 🔷 Les formes | Trouver la forme · La forme qui va avec · Paires de formes |
| 🔤 L'ABC de la Bible | La première lettre · J'écoute la lettre · Mes premières syllabes |
| 🐑 La brebis perdue | Cherche la brebis · Ramène les brebis · L'histoire du berger |
| 📖 Qui ? Quoi ? Où ? | Les questions · Qui va avec quoi ? · Vrai ou pas vrai ? |
| 💛 Je fais plaisir à Elohîm | Oui ou non ? · Que fais-tu ? · Les gestes gentils |
| 👏 Les versets | Le verset qui tape · Le mot qui manque · Les mots en ordre |

On y trouve aussi les petites prières (matin, repas, soir) et un diplôme quand les 30 étoiles sont gagnées.

Versets : Bible de Yéhoshoua ha Mashiah (BYM).

## Jouer

- **En ligne :** ouvrez la page GitHub Pages du dépôt.
- **Sur ordinateur :** téléchargez `index.html` et double-cliquez dessus.

Le jeu tient dans un seul fichier, sans installation. La voix est celle de l'appareil : pour la plus douce, utilisez Microsoft Edge (voix « Denise » ou « Vivienne ») ou Chrome (« Google français »). Les étoiles sont gardées dans le navigateur.

## Pour les parents

Jouez ensemble : 10 minutes par jour suffisent. Pour les 3–4 ans, montrez et nommez ; pour les 5–6 ans, laissez l'enfant lire les mots et les syllabes.
